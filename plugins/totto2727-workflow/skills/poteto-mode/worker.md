# Worker brief

Read the assignment before acting. Confirm the intended workspace, owned paths, and requested harness. Report a mismatch to the coordinator before editing.
Work only within the assigned scope. Do not create other workers, modify shared configuration, commit, publish, or clean up another session unless the assignment expressly requests it.

Run the assigned check and record the command, result, and any untested path. Return the changed paths and enough evidence for the coordinator to reproduce the result. If blocked, state the last verified fact and the missing prerequisite.
For a supervised Orca dispatch, use the reporting and question channels in its preamble. A shell task instead returns through its own output and exit status. Neither a terminal receipt nor a plan is a completed result.
