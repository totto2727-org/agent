# Choose a workflow

For an environment question, use [Check pstack setup](../setup-pstack/SKILL.md). For a task, find its starting point in the [Poteto mode playbook table](../poteto-mode/SKILL.md). For a question about which agent runs where, explain the distinction between a worker, a handoff, and a shell task using the [Orca adapter](../poteto-mode/references/orca.md).

If the user wants help wording a task, use the [prompt guide](references/prompting.md). If they want an example to adapt, select one [recipe](references/recipes.md). Lead with the recommendation and one concrete next step. Do not launch an agent or change configuration to answer a help question.
