# Check pstack setup

Follow the discovery steps in the [Orca adapter](../poteto-mode/references/orca.md). Report the selected execution host, target workspace, registered agent IDs, and which route fits the requested task. A registered agent is not evidence of authentication or successful execution.

Use the current harness settings unless the user requests a change. Confirm requested model or effort options against the selected harness and installed Orca guide. Do not create a pstack settings file, install software, or change account defaults as part of this check.
If Orca or the requested harness is unavailable, name the missing prerequisite. Use [Poteto mode](../poteto-mode/SKILL.md) to start work once the route is clear.
