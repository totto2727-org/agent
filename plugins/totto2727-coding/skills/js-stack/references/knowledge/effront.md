# Effront Integration

Use the maintained [Effront repository](https://github.com/totto2727-org/effront) for the installed release's documentation.

Select RSC, SSR, and browser imports from the package's conditional exports.
Check Effect, React, Vite, Alchemy, and adapter peer compatibility together under [dependency safeguards](../stack/share.md#dependency-versions).
Effront's Alchemy adapter is separate from core.
Check its supported host and lifecycle rather than inferring adapter support from framework-level claims.
