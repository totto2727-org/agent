# Review across projects

For a review overview across projects, open **Issues** in the sidebar for the selected workspace.
Use the review tabs, or `/issues?workspace=<workspace-slug>&review=in_review&view=list`, to find issues with targets ready for review.
The `review` filter accepts `in_review`, `fixing`, `changes_requested`, or `active` for any of these three unfinished target states.
These filters match review-target statuses, not the owning issue's status, and exclude `done` targets.
From a project-scoped issue list, use **全プロジェクトのレビュー** to open the workspace review overview without the current project or assignee filters.
Other review-tab links preserve the current scope and filters.
The overview covers only authorized projects in the selected workspace, not other workspaces or inaccessible projects.
It does not bypass project permissions or establish complete coverage of inaccessible work.
Open each issue's review-target view to inspect the actual attachments and feedback before acting.
