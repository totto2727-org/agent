# Lumen Note

Lumen Note はサポートの引き継ぎに使うローカルのノート要約ツールです。インシデントを診断するツールではありません。
配列の実験から Set の処理に変わりました。将来は汎用プラットフォームになるかもしれません。
ホスト型ワークフローと比べると、アーキテクチャの階層は控えめです。
Node 24 をインストールしてください。先に Node 24 のインストールを確認してください。パッケージのインストールは不要です。

```sh
node cli.mjs --remote note.txt
```

UTF-8 ファイルをローカルで読み、アップロードしません。行数と、出現順に重複を除いたタグを返します。
空行は数えません。`#` で始まる行がタグです。
