# Lumen Note

Lumen Note は、サポートの引き継ぎ用にローカルのノートを要約します。インシデントの診断はしません。
Node 24 を使います。パッケージ、アカウント、認証情報は不要です。
このディレクトリで、サンプルの UTF-8 ファイルを要約します。

```sh
node cli.mjs --local note.txt
```

出力:

```json
{ "lines": 4, "tags": ["handoff", "urgent"] }
```

`lines` はタグ行を含む空行以外の行数です。`#` で始まる行がタグです。
`tags` は重複を除き、最初に現れた順序を保ちます。
`note.txt` を手元のファイルパスに置き換えてください。ファイルは UTF-8 として読み取り、アップロードしません。
